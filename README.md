# Task Manager v0.2.0

Учебное приложение для управления задачами с графическим интерфейсом на
`tkinter` и сохранением данных в JSON.

## Возможности

- создание и редактирование задач;
- удаление с подтверждением;
- переключение статуса «выполнено»;
- сохранение названия, описания, автора и даты создания;
- автоматическая загрузка данных после перезапуска;
- совместимость со старым форматом `saves.json`, содержащим список строк.

## Архитектура

- `src/task.py` — модель `Task` и преобразование в/из словаря;
- `src/storage_manager.py` — загрузка, сохранение и CRUD в JSON;
- `src/components.py` — оформленные наследники Tkinter-виджетов;
- `src/interface_TM.py` — построение и обновление Tkinter-интерфейса;
- `src/task_manager.py` — фасад, связывающий компоненты приложения;
- `src/main.py` — точка входа.

## Запуск

Из корня проекта:

```powershell
python -m src.main
```

Также поддерживается прямой запуск:

```powershell
python src/main.py
```
